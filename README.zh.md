# 红笺工坊（演示店铺）

这是一个前端演示用的小红书文案 / 对标成稿服务店，版式接近常见的深色店铺站，但品牌、文案、插画和页脚均为原创。

**本站不会真实扣款，也不会接入支付宝、微信或银行卡。** 登录、购物车、收藏和订单只保存在当前浏览器的 `localStorage` 中。

## 如何打开

任选一种方式：

1. 用本地静态服务打开（推荐）

```bash
cd /workspace/hongjian-shop
python3 -m http.server 8787
```

然后在浏览器访问：<http://127.0.0.1:8787/>

2. 直接打开 `index.html`

也可以把 `index.html` 拖到浏览器里（`file://`）。本站使用相对路径和普通脚本，不依赖 ES Module，一般可以直接打开。若某个浏览器限制了本地存储，请改用上面的本地服务。

## 页面与功能

- 店铺首页：顶栏、店铺卡片、热卖轮播、分类导航、搜索、卡片/列表切换、收藏筛选
- 服务介绍、热门套餐、帮助中心
- 服务详情：加购、立即购买、收藏
- 购物车、确认订单、演示支付、支付成功
- 订单列表 / 详情、示例成稿交付、申请修改、评价
- 演示登录 / 注册、个人中心、消息 inbox
- 左侧快捷入口、浅色/深色主题

清理站点数据或更换浏览器后，演示订单会消失。
